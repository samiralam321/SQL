# SQL Learning Repository

A complete SQL learning repository where I learned and practiced SQL from the basics to advanced concepts, with a focus on database fundamentals, backend development, and interview preparation.

This repository contains my notes, SQL queries, examples, and practice work organized module-wise.

---

## What I Learned

The course covers SQL from beginner level to advanced topics:

- Database and SQL fundamentals
- Creating databases and tables
- INSERT, SELECT, UPDATE and DELETE
- Filtering and sorting data
- Constraints
- Aggregate functions
- GROUP BY and HAVING
- SQL JOINs
- Subqueries
- String, Date and Mathematical functions
- CASE statements
- Indexes and query performance
- Normalization
- Views and Stored Procedures
- Transactions and ACID
- CTEs
- Window Functions
- SQL for Backend Development
- Real-world SQL project and interview preparation
